# seasonal-agriculture-performance-analysis
# Seasonal Agriculture Performance Analysis

## About
This is a **Major Project** submitted as part of the **AICTE-VOIS (Vodafone Idea Foundation) Data Analytics & Visualization Internship** conducted in collaboration with **Edunet Foundation**.

## Project Overview
This project analyzes a seasonal agriculture performance dataset containing farm records across India, covering environmental conditions, resource usage, and economic outcomes. The goal is to understand how agricultural performance yield, production, profit, and resource efficiency varies across the **Kharif, Rabi, and Zaid** seasons.

## Problem Statement
Agricultural activities are influenced by seasonal variations in environmental conditions, farming practices, resource availability, and market conditions. Raw agricultural data does not clearly explain how performance changes across seasons or what patterns can be observed. This project investigates seasonal differences in agricultural performance by identifying meaningful patterns, trends, relationships, and variations within the dataset.

## Objective
- Explore and clean the dataset
- Compare agricultural performance across seasons
- Identify seasonal patterns, trends, and relationships
- Apply statistical and visualization techniques
- Derive data driven insights and recommendations for seasonal agricultural planning

## Tools & Technologies
- Python
- Pandas & NumPy (data cleaning and analysis)
- Matplotlib & Seaborn (data visualization)
- Google Colab

## Key Analysis Performed
- Season-wise Yield, Production, and Profit comparison
- Environmental conditions and resource usage across seasons
- Correlation analysis between environmental factors and yield
- Economic performance (cost, revenue, profit margin) by season
- Outlier detection in profit using the IQR method
- Disease/pest risk and seed quality comparison across seasons
- State-wise seasonal yield patterns
- Irrigation method effect on water efficiency

## Key Findings
- Kharif season shows the highest yield and profit variability along with the highest disease/pest risk (54.47%)
- Zaid season shows more stable profit outcomes and the lowest disease/pest risk (38.22%)
- Seed quality remains consistent across all seasons, indicating it is not season-dependent
- Rainfall, humidity, and temperature significantly influence yield and profit outcomes
